# Managing tasks workflow

I want to be able to create tasks in simple Trello-like Kanban-style tool that can be shared with you.

## What I expect from this tool - usage

- I can create a backlog of tasks, and a running sprint (to be done, doing, to be reviewed, done, ... non exhaustive)
- You can create your own tasks through an API
- You can read them, change their status as you push code on a Github branch

## Constraints

- It must be free or self hosted on my Raspberry Pi.
