# General enhancements

> 🕒 Brief posted on Monday 2026/10/19 14:36
>
> 🕒 Brief settled on Monday 2026/10/19 15:15

## Landing page

### Your bands

- The role should start with a capital letter (also on the lineup's band leader badge)
- Show the instrument icons

## Lineup

- The current user should be first in the list, then the others in alphabetical order by display name (strictly: no priority for band leaders)

## Repertoire

### Song list item

On a phone, the title can be cut off (…). This should not happen: a long title wraps onto 2 lines.
New layout proposal:

- Line 1: title aligned left, status aligned right
- Line 2: artist aligned left, duration + key + tempo + energy aligned right

### Add song form

This form should not contain the notes.

### Song page

- Notes should be displayed in a last block, with
  - Title: Notes
  - A multi-line text input, editable
  - A Save button

- Editing a song should be done block by block
  - Main block: title + artist, edited in a form opened by the top pencil button
  - Properties block: durations, tempo…, edited in a new form opened by its own pencil button
  - Notes block: as stated above
