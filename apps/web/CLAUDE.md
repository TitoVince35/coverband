# Web app (`apps/web`)

React + Vite + TanStack Router/Query. Cross-cutting rules are in the root `CLAUDE.md`. **Mobile-first:** design for a phone, then widen.

## Routes and data

- File-based routes in `src/routes/` (TanStack Router). `routeTree.gen.ts` is generated by the Vite plugin and committed; never edit it.
- Pages needing a login go under `routes/_app/` (pathless layout that redirects to `/login`); public pages (login, invitations) outside it.
- Band pages go under `routes/_app/b.$bandSlug/`, inside the band layout (`b.$bandSlug.tsx`: band switcher, band leader's edit button, tabs).
- Server data goes through TanStack Query and the typed `api` client from `@/lib/api`. Use `ensureOk(res)` on API responses and display errors with `errorMessage(t, error)` from `@/lib/errors`.
- **Cache:** queries are fresh for 5 minutes (`STALE_TIME`, `createQueryClient()` in `src/lib/query-client.ts`), so focus and reconnect don't refetch: the serverless database is billed per minute awake. A query whose data changes elsewhere and must be exact sets a shorter `staleTime` (the invitation page uses 0). **Every mutation invalidates the queries it changes**, so the user's own changes show at once. Logging out uses `clearUserData()` and logging in `removeUserQueries()`, so another account never sees the previous one's cached data.
- Auth: `authClient` and `sessionQuery` from `@/lib/auth`. Wrap Better Auth client calls in `ensureAuthOk()`, which throws an `AuthRequestError` (status + Better Auth code such as `INVALID_TOKEN`).
- A new password is always typed twice with `NewPasswordFields` / `readNewPassword` (`src/components/account/`): onboarding, reset and change forms.
- Import app code with the `@/` alias.

## UI

- shadcn/ui (Radix base) in `src/components/ui/`, added with `bunx --bun shadcn@latest add <name>` from `apps/web`. Icons from `lucide-react`. `cn()` comes from shadcn's `cn` package.
- Theme from shadcn preset `b6p43rVk5Q` (style `radix-maia`, mauve neutrals, emerald primary, Noto Sans body, Montserrat headings via `font-heading`); theme tokens live in `src/index.css`. Brand colour `#007a55` (emerald-700) is used for the logo and the light-mode `theme-color`.
- **Colour theme:** dark by default, with a Light / Dark / System switch in the header, saved in `localStorage` (`coverband-theme`). Logic in `src/lib/theme.ts`, duplicated in an inline script in `index.html` that applies it before first paint: **keep both in sync**. Always style for both themes (`dark:` variants or theme tokens like `bg-background`).
- Show a person with `UserAvatar` (`src/components/user-avatar.tsx`): their photo from an `avatarUrl` (the API gives it; for the session user, `sessionAvatarUrl(user)`), else a `boring-avatars` face drawn from their ID. Decorative: always show the name next to it. The account page's avatar card uploads photos, cropped and resized in the browser (`src/lib/avatar.ts`).
- **Instruments:** codes, labels (both languages) and synonyms live in `@coverband/shared` (`INSTRUMENTS`, `INSTRUMENT_NAMES`: the API matches free text too), with `matchInstrument`, `toInstrument`, `instrumentLabel` and `searchInstruments`. An instrument is `{ code }` or free text `{ label }`. Show it with `InstrumentIcon` (`src/components/instrument-icon.tsx`): Lucide where it has the instrument, the others drawn in Lucide's style (24 × 24, 2 px round strokes, `currentColor`), a music note for free text. A new instrument needs names in both languages and an icon (tested).
- Invitation UI is shared by admins and band leaders: `src/components/invitations/` (the "+" modal and the pending list). The onboarding wizard: `routes/invite.$token.tsx` + `src/components/onboarding/`; it shows in the invitation's language unless the device has a saved choice. It tells band leaders to choose the band name carefully (it can't change).

## i18n

- Add every key to both `src/i18n/locales/en.json` and `fr.json` and use `t("section.key")` from `useTranslation()`. Keys are typed from `en.json` (a typo fails the typecheck) and a test checks both files have the same keys.
- Language = saved choice (`localStorage` `coverband-language`), else the browser's languages, else English. Language names in the switch stay in their own language.
- Format dates and numbers with `Intl` and `i18n.language`; durations stay `m:ss` via `formatDuration`.

## PWA

`vite.config.ts` imports `APP_NAME` from `@coverband/shared` (manifest, `%APP_NAME%` in `index.html`): the `dev`, `build` and `preview` scripts use `--configLoader runner` so Vite can load the shared package's TypeScript.

Configured in `vite.config.ts` (vite-plugin-pwa, auto-update). Icons in `public/` are generated from `public/logo.svg` with `bunx pwa-assets-generator --preset minimal-2023 public/logo.svg`.
