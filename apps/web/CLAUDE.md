# Web app (`apps/web`)

React + Vite + TanStack Router/Query. Cross-cutting rules are in the root `CLAUDE.md`. **Mobile-first:** design for a phone, then widen.

## Routes and data

- File-based routes in `src/routes/` (TanStack Router). `routeTree.gen.ts` is generated by the Vite plugin and committed; never edit it.
- Pages needing a login go under `routes/_app/` (pathless layout that redirects to `/login`); public pages (login, invitations) outside it.
- Band pages go under `routes/_app/b.$bandSlug/`, inside the band layout (`b.$bandSlug.tsx`: band switcher, band leader's edit button, tabs).
- Server data goes through TanStack Query and the typed `api` client from `@/lib/api`. Use `ensureOk(res)` on API responses and display errors with `errorMessage(t, error)` from `@/lib/errors`.
- Auth: `authClient` and `sessionQuery` from `@/lib/auth`.
- Import app code with the `@/` alias.

## UI

- shadcn/ui (Radix base) in `src/components/ui/`, added with `bunx --bun shadcn@latest add <name>` from `apps/web`. Icons from `lucide-react`. `cn()` comes from shadcn's `cn` package.
- Theme from shadcn preset `b6p43rVk5Q` (style `radix-maia`, mauve neutrals, emerald primary, Noto Sans body, Montserrat headings via `font-heading`); theme tokens live in `src/index.css`. Brand colour `#007a55` (emerald-700) is used for the logo and the light-mode `theme-color`.
- **Colour theme:** dark by default, with a Light / Dark / System switch in the header, saved in `localStorage` (`coverband-theme`). Logic in `src/lib/theme.ts`, duplicated in an inline script in `index.html` that applies it before first paint: **keep both in sync**. Always style for both themes (`dark:` variants or theme tokens like `bg-background`).
- Invitation UI is shared by admins and band leaders: `src/components/invitations/` (the "+" modal and the pending list). The onboarding wizard: `routes/invite.$token.tsx` + `src/components/onboarding/`; it shows in the invitation's language unless the device has a saved choice.

## i18n

- Add every key to both `src/i18n/locales/en.json` and `fr.json` and use `t("section.key")` from `useTranslation()`. Keys are typed from `en.json` (a typo fails the typecheck) and a test checks both files have the same keys.
- Language = saved choice (`localStorage` `coverband-language`), else the browser's languages, else English. Language names in the switch stay in their own language.
- Format dates and numbers with `Intl` and `i18n.language`; durations stay `m:ss` via `formatDuration`.

## PWA

Configured in `vite.config.ts` (vite-plugin-pwa, auto-update). Icons in `public/` are generated from `public/logo.svg` with `bunx pwa-assets-generator --preset minimal-2023 public/logo.svg`.
